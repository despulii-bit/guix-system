#+TITLE: Guix System & Home Configuration
#+AUTHOR: despulii
#+DESCRIPTION: Monorepo for GNU Guix system declarations, Guix Home environment, channel profiles, and Nix integration.

* Overview

This repository contains the full declarative configuration for my GNU Guix machine, including operating system settings, user-level home configurations, channel definitions, and Nix Flake package management.

* Directory Structure

** =meta/=
Contains metadata, repository definitions, and system-wide Guix channels.
- ~channels.scm~ :: Specifies the Guix channels (e.g., official ~guix~, ~nonguix~) used for system updates and package definitions.

** =user/=
Contains GNU Guix Home specifications for managing the user profile, dotfiles, and user-installed packages.
- ~guix-home-config.scm~ :: The central Guix Home environment declaration handling user packages, font dependencies, shell environments, and user-level service configurations.

** =nix/=
Contains declarative Nix Flake declarations for packages managed via Nixpkgs.
- ~flake.nix~ :: Defines non-Guix packages (e.g., ~ungoogled-chromium~) installed into the user profile.
- ~flake.lock~ :: Lockfile pinning the ~nixpkgs~ revision for reproducible builds.

** =system/=
Contains core system-level declarations and hardware-specific configurations.
- ~config.scm~ :: The primary ~operating-system~ declaration defining system services, users, bootloader, kernel, and file systems.
- ~nonguix.scm~ :: System configurations or channel integrations specifically tailored for non-free kernels, microcode, or proprietary drivers.

* Usage

** Deploying System Configuration
To reconfigure the operating system state:
#+begin_src sh
sudo guix system reconfigure system/config.scm
#+end_src

** Deploying User Home Configuration
To apply user-level profile updates, dotfiles, and automatic Nix Flake additions:
#+begin_src sh
guix home reconfigure user/guix-home-config.scm
#+end_src

** Managing Nix Packages
Nix Flake integration is wired directly into Guix Home activation hooks. Adding or updating packages in =nix/flake.nix= and running =guix home reconfigure user/guix-home-config.scm= will automatically apply changes to your user profile.

** Updating Channels
To pull the latest revisions from defined channels:
#+begin_src sh
guix pull -C meta/channels.scm
#+end_src
